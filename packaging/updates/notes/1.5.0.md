Forward now connects to many more printers. Alongside Bambu, it supports Klipper (Moonraker), OctoPrint, Creality, Flashforge (including older models), Duet, Snapmaker 2.0, UltiMaker S-line, Dremel, ESP3D and MKS Wi-Fi boards, legacy QIDI printers, Repetier-Server, and SimplyPrint cloud printers. Printers whose slicer presets come from other brands are matched to the right connection type automatically.

A new preference, **Quit when the window closes**, makes closing Forward's window quit the app. It is off by default, so Forward keeps running in the menu bar or tray and the web slicer can still send to printers. If a plate is transferring when you close the window, Forward finishes sending it first.

On macOS, the File menu has a **Close** item, and Forward's window no longer reopens blank after macOS reclaims its memory in the background.
